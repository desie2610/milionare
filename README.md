# milionare

# Хто хоче стати мільйонером?

Браузерна вікторина українською мовою, побудована на React та Vite.

## Запуск

```bash
npm install
npm run dev
```

Питання автоматично зберігаються у localStorage. Необов'язкові аудіофайли можна додати до `src/assets/audio/` з такими назвами: `background.mp3`, `correct.mp3`, `wrong.mp3`, `final.mp3`, `button.mp3`, `lifeline.mp3`, `win.mp3`.
